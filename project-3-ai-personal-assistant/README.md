# Project 3 — AI Personal Assistant

## Overview

This project is an AI-powered personal assistant built with **n8n**.

The workflow combines an AI Agent with a Groq chat model, short-term conversation memory, Google Calendar, Gmail, and Google Sheets tools.

The assistant can understand natural-language requests and decide which connected tool to use. It can retrieve calendar events, read emails, and query sponsorship inquiry records from Google Sheets.

This project demonstrates how n8n can connect an LLM with external tools and real-world data sources to create a practical AI assistant.

---

## Workflow Architecture

```text
Chat Message
     ↓
  AI Agent
     │
     ├── Groq Chat Model
     │
     ├── Simple Memory
     │
     ├── Google Calendar
     │
     ├── Gmail
     │
     └── Google Sheets
```

The **AI Agent** acts as the central decision-making component. It receives the user's request, determines whether a tool is required, calls the appropriate tool, and generates the final response.

## Workflow Components

### 1. Chat Trigger

The workflow starts with the **When chat message received** node.

Users can interact with the assistant through the n8n chat interface using natural-language requests.

Examples:

```text
What does my calendar look like tomorrow?
```

```text
Summarize my recent emails.
```

```text
Do we have any new sponsorship requests?
```

The chat trigger passes the user's message to the AI Agent.

---

### 2. AI Agent

The **AI Agent** is the core of the workflow.

Its system instructions define how it should interact with the available tools.

The agent is instructed to:

* Act directly on user requests.
* Avoid unnecessary confirmation questions.
* Use tools when the request requires external data.
* Avoid inventing information.
* Clearly state when a tool returns no data.
* Use the user's local timezone unless another timezone is specified.
* Provide concise and action-oriented responses.
* Produce clean, copy-pasteable text when drafting email replies or summaries.

The agent has access to three external tools:

1. Google Calendar
2. Gmail
3. Sponsor Inquiry Tracker in Google Sheets

---

### 3. Groq Chat Model

The workflow uses the **Groq Chat Model** as the AI Agent's language model.

The configured model is:

```text
openai/gpt-oss-120b
```

The configured maximum output token setting is:

```text
800
```

The model is connected directly to the AI Agent as its language model.

---

### 4. Simple Memory

The workflow includes n8n's **Simple Memory** node using `memoryBufferWindow`.

It provides short-term conversational memory to the AI Agent, allowing the assistant to maintain context across messages within the conversation.

No specific memory-window size is configured in the exported workflow, so this README does not assume a particular number of remembered messages.

## AI Tools

### 5. Google Calendar Tool

The **Get many events in Google Calendar** node is connected to the AI Agent as a tool.

It uses the `getAll` operation to retrieve calendar events.

The assistant is instructed to use this tool when the user asks about:

* Schedule
* Availability
* Free time
* Existing commitments
* Events within a specific date or time range

For example:

```text
What does my calendar look like tomorrow?
```

The agent retrieves the available calendar events and summarizes the relevant commitments and available time based on the returned data.

The calendar tool is **read-only** in this workflow. It does not create, modify, or delete calendar events.

---

### 6. Gmail Tool

The **Read Email** node is connected to the AI Agent as a tool.

It uses the `getAll` operation to retrieve emails.

The agent is instructed to use Gmail when the user asks about:

* Latest emails
* Important emails
* Emails from a particular sender or domain

The intended response format is:

```text
From:
Subject:
Gist:
Action items / deadlines:
```

The Gmail tool is **read-only** in this workflow. It retrieves email data but does not send, delete, or modify emails.

---

### 7. Sponsor Inquiry Tracker

The **Get row(s) in sheet in Google Sheets** node connects the AI Agent to a Google Sheets sponsorship inquiry tracker.

The agent is instructed to use this tool whenever the user asks about sponsorship inquiries or requests.

The tool retrieves rows from the configured spreadsheet and allows the AI Agent to read the available sponsorship data.

This connects Project 3 with the data generated by the previous **Lead / Sponsorship Intake Automation** workflow.

## Architecture Pattern

This project demonstrates a **tool-using AI agent** pattern:

```text
User
 ↓
Chat Trigger
 ↓
AI Agent
 ↓
LLM decides whether a tool is required
 ↓
┌──────────────┬──────────────┬──────────────┐
│   Calendar   │    Gmail     │ Google Sheets│
│    (Read)    │    (Read)    │    (Read)    │
└──────────────┴──────────────┴──────────────┘
 ↓
AI Agent
 ↓
Response
```

The important concept is that the LLM is not simply connected to the external services as a fixed sequential workflow.

Instead, the **AI Agent receives the tools and decides when a tool is relevant** based on the user's request.

## Setup

### 1. Start n8n

Run your local n8n installation:

```bash
n8n
```

Open the n8n editor:

```text
http://localhost:5678
```

### 2. Import the Workflow

1. Open n8n.
2. Import `project-3-ai-workflow-automation.json`.
3. Review the AI Agent and connected tools.
4. Configure your own Groq credentials.
5. Configure your own Google Calendar credentials.
6. Configure your own Gmail credentials.
7. Configure your own Google Sheets credentials.

### 3. Configure Google Resources

The exported workflow references specific Google Calendar and Google Sheets resources.

When importing the workflow into another n8n instance:

* Select the appropriate Google Calendar.
* Select the appropriate Google Sheets document.
* Verify that the required sheet is available.
* Ensure the connected Google account has the required permissions.

### 4. Test the Assistant

Use the n8n chat interface and test requests such as:

```text
What does my calendar look like tomorrow?
```

```text
Summarize my recent emails.
```

```text
Do we have any new sponsorship requests?
```

Verify that the AI Agent selects the appropriate tool and bases its response on the returned data.

### 5. Activate the Workflow

The supplied workflow is currently inactive.

After configuring the required credentials and verifying the workflow, activate it from the n8n editor.

## Security

The workflow connects to personal Google services and an external LLM provider, so credentials and resource identifiers should be handled carefully.

Before committing the workflow to a public repository:

* Do not publish Groq API keys or other API secrets.
* Do not publish Google OAuth access tokens or refresh tokens.
* Do not expose passwords or other authentication secrets.
* Review Google Calendar IDs before publishing.
* Review Google Sheets document IDs before publishing.
* Do not expose private OAuth credential information unnecessarily.
* Use your own Google resources when importing the workflow.
* Keep credentials configured inside n8n rather than hardcoding secrets into the workflow.
* Review exported workflow metadata before making the repository public.

The supplied workflow currently contains:

```json
"pinData": {}
```

Therefore, there is no pinned test submission data in this particular export.

A `.gitignore` should also exclude environment and credential files, for example:

```text
.env
.env.*
credentials.json
*credentials*
```

However, `.gitignore` does **not** remove sensitive information embedded directly inside a workflow JSON export. The JSON itself must therefore be reviewed and sanitized before being committed to a public repository.

## Current Scope and Limitations

This workflow intentionally focuses on **read-oriented AI assistance**.

The current tools can:

* Read calendar events.
* Read emails.
* Read sponsorship inquiry records.
* Maintain short-term conversation context.
* Generate responses using the configured LLM.

The workflow does **not** currently provide tools for:

* Creating calendar events.
* Editing calendar events.
* Deleting calendar events.
* Sending emails.
* Modifying emails.
* Writing or updating Google Sheets records.

These capabilities could be added later by connecting appropriate write-enabled tools, but they are outside the scope of this project.

## Key Takeaways

This project demonstrates several important n8n AI concepts:

* Building an AI Agent inside n8n.
* Connecting an LLM to an agent.
* Giving an agent external tools.
* Letting the agent choose which tool to use.
* Using short-term conversation memory.
* Connecting AI to Google Calendar.
* Connecting AI to Gmail.
* Connecting AI to Google Sheets.
* Building natural-language interfaces over existing data.
* Designing tool access with explicit read-only boundaries.

The core pattern is:

```text
LLM + Memory + Tools + Agent
```

Instead of creating a separate fixed workflow for every user request, the AI Agent provides a natural-language interface and determines which available tool is relevant to the request.
